📦 How to install the extension:
  1. Download the generated extension package (.zip file)
  2. Log in to your EspoCRM instance
  3. Go to Administration → Extensions
  4. Click Install and upload the .zip file
  5. Wait for installation to complete - EspoCRM will automatically rebuild
  6. Your new entity is now ready to use!
🔗 Finalize Kobo Connect REST Service:

The REST service has been created in Kobo with placeholder values. Complete these steps to activate automatic data sync:

  1. Create API Role in EspoCRM:
    • Go to Administration → Roles → Create Role
    • Name it something like "YourEntityAPI"
    • Under "Scope Level", find your entity and set: Create = Yes, all others = No
    • Save the role
  2. Create API User:
    • Go to Administration → Users → Create User
    • Type: API
    • Username: "yourentityapi"
    • Assign the role you just created
    • Save and copy the API Key that appears
  3. Update REST Service in Kobo:
    • Log in to your Kobo account
    • Open your form → Settings → REST Services
    • Find the "Kobo Connect → EspoCRM" service
    • Click Edit
    • Update custom headers:
      • targetkey: Replace YOUR-API-KEY with the API key from step 2
      • targeturl: Replace YOUR-ESPO-INSTANCE with your EspoCRM URL (e.g., https://your-instance.com/) Note: Include the trailing slash!
    • Save the REST service
  4. Test the Connection:
    • In Kobo, submit a test form entry
    • Check your EspoCRM entity - a new record should appear automatically!
    • If it doesn't work, check the REST service logs in Kobo for error messages
